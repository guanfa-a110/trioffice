# 快捷键 / Keyboard Shortcuts

> 在 macOS 上 `Ctrl` 一律对应 `⌘`。

## 全局

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/⌘ + S` | 保存当前文件 |
| `Ctrl/⌘ + P` | 打印 / 导出 PDF（Writer 打印文档，Sheet 打印表格） |
| `Esc` | 关闭弹窗 / 取消编辑 / 退出放映 |

## Writer 文档

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl/⌘ + B` / `I` / `U` | 加粗 / 斜体 / 下划线 |
| `Ctrl/⌘ + Z` | 撤销 |
| `Shift + Ctrl/⌘ + Z` | 重做 |
| `Ctrl/⌘ + F` | 查找 / 替换 |
| `Ctrl/⌘ + A` | 全选 |
| `Enter`（在表格单元格内） | 跳到下一个单元格 |
| `Shift + Enter`（在表格内） | 跳到上一个单元格 |
| `Ctrl/⌘ + V` | 粘贴（自动清理外部 HTML 里的脚本与事件属性） |

## Sheet 表格

| 快捷键 | 作用 |
| --- | --- |
| 任意字符 | 直接进入编辑（覆盖原内容） |
| `F2` | 编辑当前单元格（保留原内容） |
| `Enter` | 确认并下移 |
| `Tab` / `Shift + Tab` | 确认并右移 / 左移 |
| `Alt + Enter` | 单元格内换行 |
| `Esc` | 取消编辑 |
| `方向键` | 移动活动单元格 |
| `Shift + 方向键` | 扩展选区 |
| `Ctrl/⌘ + 方向键` | 跳到数据区边界 |
| `Ctrl/⌘ + Home` / `End` | 跳到 A1 / 最后一列 |
| `PageUp` / `PageDown` | 上翻 / 下翻一屏 |
| `Delete` | 清除内容 |
| `Backspace` | 清除内容与格式 |
| `Ctrl/⌘ + A` | 全选 |
| `Ctrl/⌘ + C` / `X` / `V` | 复制 / 剪切 / 粘贴（TSV 格式，可与 Excel 互贴） |
| `Ctrl/⌘ + Z` / `Shift + Ctrl/⌘ + Z` | 撤销 / 重做 |
| `Ctrl/⌘ + B` / `I` / `U` | 加粗 / 斜体 / 下划线 |
| `Ctrl/⌘ + F` | 查找 / 替换 |
| `Alt + =` | 自动求和（在当前选区下方插入 `SUM`） |
| `Ctrl + 滚轮` | 缩放 |
| 拖拽选区右下角小方块 | 填充柄：等差序列 / 公式平移 / 文本循环 |
| 双击单元格 | 进入编辑 |
| 右键 | 上下文菜单（插入、删除、排序、合并、图表、冻结） |

## Deck 演示

### 编辑态

| 快捷键 | 作用 |
| --- | --- |
| `F5` | 开始放映 |
| `Ctrl/⌘ + D` | 复制当前幻灯片 |
| `Ctrl/⌘ + Z` / `Shift + Ctrl/⌘ + Z` | 撤销 / 重做 |
| `PageDown` / `PageUp` | 切换到下 / 上一页 |
| `方向键` | 微调选中元素 1px |
| `Shift + 方向键` | 微调选中元素 10px |
| `Delete` / `Backspace` | 删除选中元素 |
| `Esc` | 取消选中 |
| 双击文字元素 | 就地编辑文字 |
| 右键缩略图 | 复制 / 上移 / 下移 / 删除幻灯片 |

### 放映态

| 快捷键 | 作用 |
| --- | --- |
| `→` `↓` `Space` `Enter` `PageDown` | 下一页 |
| `←` `↑` `PageUp` | 上一页 |
| `Home` / `End` | 首页 / 末页 |
| `F` | 切换全屏 |
| `Esc` | 退出放映 |
| 单击画面 | 下一页 |
