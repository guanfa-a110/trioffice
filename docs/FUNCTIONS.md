# 公式函数手册 / Function Reference

TriOffice 表格内置 **202** 个公式函数（含常用别名），无需插件、无外部依赖。

> 本文件由 `node scripts/make-docs.mjs` 从 `src/apps/sheet/functions.js` 自动生成，请勿手工编辑。

## 快速上手

```text
=SUM(A1:A10)                     求和
=IF(B2>=60,"及格","不及格")       条件判断
=SUMIF(C2:C99,"华东",D2:D99)      按条件求和
=VLOOKUP(A2,表2!A:D,3,FALSE)      跨表查找
=Sheet2!A1*1.1                    跨表引用
=SUM(A:A)                         整列引用
=A1*$B$1                          绝对引用（填充时不变）
```

支持的运算符：`+ - * / ^ & %`、比较运算 `= <> < > <= >=`，以及 `{}` 数组常量（如 `{1,2;3,4}`）。

## 错误码

| 错误码 | 含义 |
| --- | --- |
| `#DIV/0!` | 除数为零 |
| `#VALUE!` | 类型不匹配（例如把文字当数字） |
| `#REF!` | 引用已失效（被引用的行/列被删除） |
| `#NAME?` | 函数名或名称拼写错误 |
| `#NUM!` | 数值超出定义域（如负数开方） |
| `#N/A` | 查找不到结果 |
| `#CIRC!` | 循环引用（TriOffice 特有标记） |

## 数字格式

共 8 种预设：`general`、`number`、`currency`、`percent`、`date`、`time`、`scientific`、`text`。
